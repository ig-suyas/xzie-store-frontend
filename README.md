# haul: React storefront (v2)
1. `npm install`
2. `.env` is already filled in (API base URL, Google client ID, currency). Edit it if your backend runs elsewhere.
3. `npm run dev` then open http://localhost:5173
4. `npm run build` for production (serve `dist/` with an SPA fallback to index.html).
Fonts are self-hosted through npm packages, icons are Phosphor, motion uses the `motion` package.
